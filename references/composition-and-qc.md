# A3·A4·B4·8절 조판과 검수

## 용지 프로필

| 프로필 | 크기 | 기본 방향 | 기본 단 수 |
|---|---:|---|---:|
| A3 | 297×420 mm | 세로 | 2 |
| A4 | 210×297 mm | 세로 | 2, 가독성 우선 시 1 |
| B4-JIS | 257×364 mm | 세로 | 2 |
| B4-ISO | 250×353 mm | 세로 | 2 |
| 8JEOL | 272×394 mm | 세로 | 2 |
| GUKJEON-8JEOL | 234×318 mm | 세로 | 2 |

`B4`는 B4-JIS 별칭이다. `8절`·`8절지`는 4×6판 8절 272×394mm를 뜻하고,
국전 8절은 234×318mm로 별도 지정한다. 실제 인쇄소 재단 크기나 비인쇄 여백이 다르면
가까운 프로필을 임의로 쓰지 말고 규격을 확인한다.

## 논리 순서

```text
시험 머리말
Bundle 1 Stimulus Fragment
Bundle 1 선택 Question Fragment
Bundle 2 Stimulus Fragment
Bundle 2 선택 Question Fragment
...
```

독립 문항은 Stimulus가 없는 1문항 Bundle로 취급한다. 문제지에 해설 자산을 넣지 않고,
답지에 선택하지 않은 문항의 해설을 넣지 않는다.

## 가상 연속 스트립

모든 자산을 단 너비로 정규화하고 논리 순서대로 하나의 가상 y축에 놓는다. 실제로 긴
이미지나 비정상적인 페이지를 만들지 않고 전역 y 위치와 원본 픽셀 범위만 계산한다.

```text
Stimulus F01 → Stimulus F02 → Question 1 → Question 2 → …
                   │ 단 높이 H │ 단 높이 H │ 단 높이 H │
                     1쪽 왼쪽     1쪽 오른쪽   2쪽 왼쪽
```

2단에서 스트립 구간 `N`의 위치:

```text
page   = floor(N / 2) + 1
column = N mod 2
```

`H`는 페이지 전체 높이가 아니라 상하 여백, 머리말, 꼬리말을 제외한 본문 높이다.

## 분할 알고리즘

1. 자산의 남은 부분이 현재 단에 들어가면 그대로 배치한다.
2. 넘으면 현재 단의 남은 높이 이전에 있는 가장 뒤쪽 안전점을 찾는다.
3. 명시적 `safe_breaks`를 우선한다.
4. `flow`이면 충분한 가로 흰 띠를 추가 후보로 쓴다.
5. 후보가 `protected_ranges`와 겹치면 제외한다.
6. 윗부분을 현재 단에 두고 아랫부분을 다음 단 맨 위에 같은 배율로 잇는다.
7. 안전점이 절단선보다 위면 남는 곳은 흰 여백으로 둔다.
8. 안전점이 없고 빈 단에는 들어가면 전체를 다음 단으로 넘긴다.
9. 빈 단에도 맞지 않으면 `min_scale_fraction`까지만 축소한다.
10. 축소 하한도 넘으면 실패한다. 임의 픽셀 절단은 금지한다.

다음 요소는 `keep-together` 또는 보호 구간으로 다룬다.

- 표와 그래프
- 그림과 범례
- 한 줄 수식과 정렬 수식 묶음
- 선택지 한 행 또는 박스
- 문제 번호만 남는 첫 줄
- 지문 범위 라벨만 남는 첫 줄

일반 지문이나 긴 발문은 안전한 행간에서 단을 넘길 수 있다. 절단선이 글자 행을 직접
가르면 직전 안전 행간에서 끊고 나머지를 다음 단으로 보낸다.

## 새 번호와 출처 표기

원번호-새번호 매핑은 문제, 정답표, 해설의 유일한 기준이다.

- 원번호 bbox만 지우고 이미지 크기는 유지한다.
- 새 번호의 마침표 오른쪽 끝, 잉크 아래선, 글자 높이를 원번호에 맞춘다.
- 긴 새 번호는 발문 쪽이 아니라 왼쪽 여백으로 확장한다.
- 공통 지문 범위 라벨도 선택된 새 번호 범위로 바꾼다.
- 원번호와 새 번호가 다른데 안전한 교체 규칙이 없으면 실패한다.

출처 표기는 사용자가 선택한 경우에만 번호 위의 검수된 빈 여백에 넣는다. 본문을
밀거나 축소하거나 가리지 않는다.

## 답지 모드

1. `key-only`: 새 번호와 정답표
2. `solutions-only`: 새 번호 순서의 해설
3. `key-and-solutions`: 정답표와 해설

정답표는 원본 표 이미지를 재사용하지 않고 AnswerEntry 데이터로 새로 그린다. 객관식
번호, 서답형 문자열, 복수 정답 상태를 보존한다.

## 출력과 원자적 전환

```text
output/<build_id>/
├─ <build_id>_problems_<paper>.pdf
├─ <build_id>_answers_<paper>.pdf
├─ selection-manifest.json
├─ composition-report.json
└─ qa/
   ├─ problems/
   └─ answers/
```

같은 `build_id`는 기본적으로 거부한다. 명시적 교체 승인에만 `--overwrite`를 쓴다.
PDF, 보고서, QA PNG를 임시 형제 폴더에서 모두 검증한 뒤 최종 폴더로 전환한다.

## 자동 검증

조판 전:

- 후보 수, 선택 수, 제외 수
- 중복 question ID와 source asset
- 문제-정답-해설 참조
- 새 번호 `1..N`
- 필요한 Stimulus 포함
- seed와 선택 재현성
- 출처 표기 선택과 annotation의 일치

조판 후:

- 문제지·답지 파일 수
- 두 PDF 다시 열기
- 모든 페이지 MediaBox
- 선택 문항, 정답, 해설 수
- 페이지 밖 bbox와 겹침
- 각 분할 자산 `source_pixel_y`가 원본 `0..height`를 누락·중복 없이 덮는지
- 모든 seam이 승인점 또는 검출 흰 띠인지
- 보호 구간을 가르는 split 0건
- 유효 DPI와 축소율 하한
- 빈 페이지 0건

QA 렌더링을 생략한 테스트 보고서는 `blank_pages: null`과
`blank_pages_checked: false`를 써야 한다. 검사하지 않은 값을 성공 상수로 기록하지
않는다.

## 전 페이지 시각 검수

- 원번호 흔적, 흰 사각형 테두리, 이중 번호가 없는가
- 새 번호의 서체·크기·기준선이 자연스러운가
- 출처 표기가 본문보다 두드러지거나 내용을 가리지 않는가
- 긴 지문이 오른쪽 단과 다음 페이지로 중복·누락 없이 이어지는가
- 문장 행, 표, 그래프, 수식, 선택지가 잘리지 않았는가
- 다음 문항 일부가 앞 문항 crop에 섞이지 않았는가
- 단 전환의 여백과 자산 간 간격이 일관적인가
- A4에서 글자가 지나치게 작지 않은가
- 문제 번호, 정답표, 해설 번호가 일치하는가
- 한국어 glyph가 네모나 깨진 글자로 렌더링되지 않았는가

접촉표는 탐색용이다. 완료 전 모든 페이지를 읽을 수 있는 배율로 확인하고 번호 교체와
출처 표기 영역은 확대 crop으로 별도 확인한다.

## 완료 판정

사용자가 요청한 파일 수와 문항 수를 정확히 검증한다. 후보 부족, 해설 누락, 조판 실패,
QA 실패가 있으면 `partial` 또는 `blocked`로 기록하고 부족한 수와 대상 ID를 명시한다.
일부 결과를 완성본으로 보고하지 않는다.
