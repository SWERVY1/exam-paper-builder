# 처음 보는 시험지·답지 분석

한 파일이 열렸다는 사실만으로 같은 폴더 전체를 같은 형식으로 처리하지 않는다. 먼저
문서별 증거를 수집하고, 형식군을 나눈 뒤 대표 샘플을 승인한다.

## 1. 입력 사전 점검

각 파일에 대해 다음을 확인한다.

- PDF 헤더와 페이지 열기 성공 여부
- 암호화, 손상, 빈 페이지, 비정상적으로 큰 페이지
- 페이지 수와 페이지별 MediaBox/CropBox
- 0/90/180/270도 회전과 페이지 안쪽의 기울어진 스캔
- 텍스트 레이어 비율과 실제 보이는 글자의 일치
- 흑백, 회색조, 컬러, 투명 배경
- 파일 stem, 과목, 시험 시기, 문제/답지 구분
- 동일 해시 파일과 이름만 다른 중복 파일

암호가 필요하거나 파일이 손상된 경우 우회하지 않는다. 읽을 수 있는 사본을 사용자에게
요청한다.

## 2. 페이지 형식 판정

PDF 전체가 하나의 레이아웃이라고 가정하지 않는다. 페이지별로 다음 특징을 기록한다.

| 특징 | 예시 | 처리 |
|---|---|---|
| 단 수 | 1단, 2단, 3단 | 페이지별 읽기 순서 확정 |
| 방향 | 세로, 가로, 회전 메타데이터 | 실제 렌더 방향으로 정규화 |
| 텍스트 상태 | 텍스트, 스캔, 혼합 | 텍스트 앵커 또는 OCR fallback |
| 번호열 | 1..N, 중간 시작, 재시작 | section 단위로 분리 |
| 공통 범위 | `[1~3]`, 지문 뒤 여러 문제 | Bundle 후보 생성 |
| 장식 영역 | 머리말, 쪽 번호, 로고, 바코드 | 본문 crop에서 제외 |
| 자료 요소 | 표, 그래프, 수식, 삽화 | 보호 구간 후보 생성 |

표지, 안내, 듣기 대본, 선택과목 전환 페이지, 정답표, 해설 본문은 서로 다른 페이지
역할로 분류한다.

## 3. 텍스트 레이어와 OCR

텍스트 레이어가 있다고 해서 신뢰하지 않는다. 글자 순서가 시각적 읽기 순서와 다르거나,
숨은 OCR 텍스트가 다른 페이지에 어긋나 있을 수 있다.

1. 텍스트 앵커로 번호 후보를 찾는다.
2. 번호 bbox가 실제 렌더에서 번호 잉크를 감싸는지 확인한다.
3. 앵커 수, 번호열, 단 위치가 서로 일치하는지 검사한다.
4. 텍스트가 없거나 불완전하면 페이지 렌더에서 OCR fallback을 사용한다.
5. OCR 후보는 자동 승인하지 않고 `needs_review`로 남긴다.

OCR 결과는 구조 판별에만 쓰고 원문 전체 텍스트를 기본 저장하지 않는다. 저장해야 하는
경우에도 최소한의 번호, 범위 라벨, 좌표, 신뢰도만 남긴다.

## 4. 문제지의 흔한 예외

- 번호가 단마다 다시 시작하거나 선택과목 구간에서 재시작함
- 한 문항이 다음 단 또는 다음 페이지까지 이어짐
- 공통 지문 안에 특정 문항만 쓰는 추가 자료가 있음
- 지문 범위 라벨보다 실제 관련 문항 수가 다름
- 문제 번호와 발문이 다른 Fragment에 있음
- 선택지 일부가 다음 페이지에 있음
- 표나 그림의 캡션이 bbox 밖으로 튀어나옴
- 스캔 그림자 때문에 흰 띠 탐지가 잘못됨
- 재단 오차로 왼쪽·오른쪽 페이지 여백이 다름
- 페이지 안에 서로 다른 두 과목이 함께 있음

이 경우 지문, 추가 자료, 문제, 선택지를 여러 Fragment로 보존하고 읽기 순서를 JSON에
명시한다. 하나의 거대한 crop으로 합치지 않는다.

## 5. 답지의 흔한 예외

- 첫 페이지는 정답표, 이후는 해설 본문
- 여러 과목의 정답표가 한 표에 함께 있음
- 2단 문제지와 달리 해설은 1단 또는 3단임
- 해설 번호가 굵은 제목이 아니라 본문 안에 있음
- 선택과목마다 1번부터 다시 시작함
- 객관식 정답과 서답형 정답이 섞임
- 정답표와 해설 본문의 정답이 충돌함
- 해설 없이 정답표만 있거나, 정답표 없이 해설만 있음

정답표의 완전한 번호열만 자동 추출 후보로 사용한다. 서답형 수식이나 충돌한 정답은
추측하지 않는다.

## 6. 문제-답지 pairing

다음 증거가 모두 맞을 때만 `verified`로 승인한다.

- 정규화한 파일 stem
- 과목과 선택과목 section
- 시행 시기 또는 사용자가 부여한 시험 ID
- 문제지의 실제 번호열과 답지의 번호열
- 예상 문항 수

동일 후보가 둘 이상이면 `ambiguous`, 답지가 없으면 `missing-solution`, 번호열이
다르면 `sequence-conflict`로 남긴다. 사용자가 해설 없는 문항을 허용하지 않았다면
선택 후보에서 제외한다.

## 7. 형식군 파일럿

폴더 전체를 자동 처리하기 전 최소한 다음 샘플을 포함한다.

- 첫 파일, 중간 파일, 마지막 파일
- 독립 문항
- 공통 지문 2문항 이상 묶음
- 단/페이지를 넘는 긴 문항
- 표·그림·수식이 있는 문항
- 번호가 재시작되는 section
- 답지의 첫·중간·마지막 해설
- 스캔 또는 OCR fallback 문서

다음 사건 중 하나가 나오면 형식군 전파를 중단한다.

- 앵커 개수 변화
- 번호 누락·중복·재시작
- 페이지 크기·회전·단 수 변화
- OCR fallback 발생
- pairing 누락 또는 충돌
- 보호 요소를 가르는 crop

## 8. 분석 결과의 최소 필드

```json
{
  "source_id": "LOCAL_EXAM_001",
  "path": "relative/local-input.pdf",
  "sha256": "...",
  "page_count": 12,
  "page_profiles": [
    {
      "page": 1,
      "width_pt": 595.28,
      "height_pt": 841.89,
      "rotation": 0,
      "columns": 2,
      "text_mode": "embedded",
      "role": "questions"
    }
  ],
  "sequence": {"first": 1, "last": 45, "events": []},
  "review_status": "needs_review",
  "review_reasons": ["new-layout-family"]
}
```

로컬 절대 경로는 작업 보고서에만 두고 공개 예시나 배포 패키지에 복사하지 않는다.
